Placed in `.claude/skills/` so it loads in Claude Code sessions on this repo (including cloud sessions, where `/plugin` is unavailable).

Requirements: Node.js and the `capcut-cli` npm package (`npm i -g capcut-cli`, or set `CAPCUT_CLI` to its `dist/index.js`).
The CLI edits CapCut project files on disk; the CapCut app itself runs on macOS/Windows.
